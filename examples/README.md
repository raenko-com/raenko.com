# Интерактивные примеры работ (RAE-21)

Самостоятельный блок «Примеры работ» для raenko.com. Чистые HTML/CSS/JS, без зависимостей и сборки.

- `index.html` — разметка секции `#examples` (вставляется на главную как есть).
- `examples.css` — стили, все классы с префиксом `rx-`, чтобы не пересекаться со стилями сайта.
- `examples.js` — логика всех демо.

Примеры:
1. **Сайт → бот → CRM** — заявка с сайта приходит в Telegram и появляется в CRM; кнопки бота «Принять»/«Позвонить» работают, статус меняется кликом.
2. **Онлайн-запись** — выбор услуги, дня и свободного слота, подтверждение и напоминание от бота в Telegram.
3. **Калькуляторы** — смета ремонта с готовым КП и калькулятор экономии на рутине.
4. **Сайт до/после** — ползунок между устаревшим и современным сайтом, режим «Телефон» (на мобильных включён сразу).

Цвета бренда: `#1E3A5F`, `#FF5A1F`, `#FFFFFF`. Клиенты и данные в демо вымышленные.

Локально: просто открыть `examples/index.html` в браузере.
