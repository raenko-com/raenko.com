# Калькулятор стоимости (RAE-18)

Блок «Сколько стоит ваш проект» для сайта. Vanilla HTML/CSS/JS, классы с префиксом `rc-`.

- `prices.js` — все опции, цены и сроки. Цены меняются здесь, без правки кода.
- `calc.js` — логика: шаг 1 выбор направлений, шаг 2 опции, итог диапазоном.
- `calc.css` — стили. Цвета только через переменные схемы (`--bg`, `--surface`, `--ink`, `--muted`, `--primary`, `--accent`, `--deep`).

Три схемы из голосования RAE-29: `indigo` (Индиго + лайм), `ultra` (Ультрамарин + солнце), `raspberry` (Малина + мята). Схема задаётся атрибутом `data-theme` на `body`. Переключатель вверху страницы нужен только для превью.

Как считается:
- цена: сумма диапазонов выбранных опций, округлённая до 5 000 ₽;
- срок: направления частично идут параллельно, поэтому берём самое долгое направление плюс 40% остальных;
- поддержка считается отдельно, в месяц; базовое SEO не добавляется, если выбран сайт; рекламный бюджет не входит.
